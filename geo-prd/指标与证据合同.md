# 指标与证据合同

版本：metrics-v1｜日期：2026-11-13｜状态：待阶段 0 评审、阶段 2 用标注集验收。

本文是主报告与各阶段共用的数据口径。示例数字为计算样例，不是试点结果。指标变更必须创建新版本，报告保存当时使用的版本。

## 1. 五类证据与来源身份

| 类型 | 主要来源 | 使用边界 |
| - | - | - |
| SearchEvidence | 搜索接口的候选网页 | 表示检索候选，不等于回答实际引用 |
| ModelAnswer | 明确服务/端点的原始回答 | 只表示该 API 链路；自建搜索加模型标记 custom_pipeline |
| ConsumerObservation | 人工观察的消费者网页/App | 保存入口、模式、账号条件、原文和时间；不能混入 API 趋势 |
| SiteObservation | 站点日志、页面清单 | 表示被观察到的访问及可用性，不能推出收录或推荐 |
| BusinessEvent | 访问、咨询、订单的授权导入 | 保留来源和关联强度，不代表因果增量 |

`channel_id` 对应实际服务、端点、模型、工具配置、采集方式的版本化配置。`target_product_label` 只是展示说明，不能替代 channel_id。模型版本未知时明确 unknown。`citation_origin` 区分 provider_native、consumer_visible、custom_pipeline、analyst_found，后两类不计第三方引擎的原生引用。

## 2. 最小证据合同

| 对象 | 必需字段 | 不变量 |
| - | - | - |
| 计划样本 | tenant_id、plan_version、prompt_version、channel_id、scheduled_slot、repeat_index | 组合唯一；重试不创建新计划样本 |
| 请求尝试 | attempt_id、sample_id、请求/结束时间、状态、provider_request_id、用量/未知状态 | 每次调用成本都留存，未知成本不按零处理 |
| 原始观察 | observation_id、evidence_type、原文指针及 hash、采集条件、时间、完整性 | 只追加；原始记录不能被分析纠错覆盖 |
| 分析版本 | observation_id、规则/模型版本、标签、证据片段、理由、复核状态 | 可重算，历史报告继续引用旧版本 |
| 引用 | 原始 URL、归一化 URL、origin、位置、字段完整性、页面抓取状态 | 引用存在与页面可访问分别判断 |
| 发布 | content_version、content_hash、approval_id、账号/渠道、回执、URL、状态 | 批准内容改动后旧审批失效 |
| 报告快照 | report_id、题集/通道/指标/分析版本、窗口、样本集合清单、排除理由 | 重新生成同版本应得到同样分母及结果 |

时间存 UTC，客户展示与日聚合默认 Asia/Shanghai；修改聚合时区需新建报告口径。目标地区与实际采集地区分开，无法识别时记 unknown。脱敏不能删除判断结果所需的公开证据片段；涉及客户资料时按访问权限处理。

## 3. 有效、合格和可判断分别计算

- P：冻结计划内的样本槽位数。计划获批暂停后，未来槽位按新版本调整，过去失败槽位不可删除。
- V：存在完整、可分析原文的有效回答。超时、验证码、登录失败、截断不可用及解析失败不计；解析修复后可以新分析版本纳入。
- E：V 中符合该计划采集条件的合格回答，例如要求联网的计划需要有可验证的联网触发证据。未知不能冒充已触发。
- Jm / Jr：E 中可判断提及 / 推荐的样本。实体歧义或无法解释的语义进入 unknown，不算否定。
- C：E 中原生引用字段完整可观察的样本。完整空列表属于 C；协议不支持、响应缺损不属于 C。

V/P 为有效覆盖，E/P 为条件合格覆盖；同时展示 (E−Jm)/E 和 (E−Jr)/E，避免排除歧义后虚高。所有分母为零的指标显示 N/A，并说明原因。有效回答未联网仍可进入独立未联网分层，但不能污染联网主指标。

## 4. 指标定义

| 指标 | 单题计算 | 汇总与展示 |
| - | - | - |
| 提及率 | Jm 内确认提及品牌的样本数 / Jm | 默认固定题等权；标注题型，附未知比例 |
| 推荐率 | Jr 内明确推荐品牌的样本数 / Jr | 主面板仅 30 道固定非品牌题；比较题、品牌题另表 |
| 自有页面引用率 | C 内至少一条已确认自有原生引用的样本数 / C | 同时显示 C/E；一条回答多次引自有页只计一次 |
| 第三方品牌支持率 | 可判断第三方支持性的样本中，存在经验证支持证据的样本数 / 可判断样本数 | URL 存在不等于支持品牌；抓取失败进入未知并展示覆盖 |
| SoV | 某品牌提及样本数 / 固定竞品集合各品牌提及样本数之和 | 同题同窗同通道；同一回答每品牌最多一次；仅是样本份额 |
| 推荐列表位置 | 有明确顺序语义且品牌被推荐时的位置 | 展示条件均值、上榜率与分布；缺席无位置，非 0 |
| 品牌事实错误率 | 人工复核确认错误的回答数 / 已复核品牌回答数 | 展示复核抽样方法和覆盖率 |
| 到期任务验收完成率 | 到期任务中已按验收条件完成的数量 / 到期任务数量 | 不把引擎效果作为发布任务本身的验收；延期天数另列 |
| 观测爬取覆盖 | 固定页面清单中有合格访问的页面数 / 清单页面数 | 必须带日志覆盖范围、身份核验规则；缺日志为 N/A |
| AI 引荐转化率 | 约定窗口内产生目标事件的可识别 AI 引荐会话数 / 同组引荐会话数 | 会话、目标、窗口固定；按会话去重；无来源不补猜 |

自有页面的归属证据来自已确认域名或平台账号/页面，不能把整个共享平台域名都算自有。SoV 的竞品集合固定版本，新增竞品后不直接拼接旧趋势。

## 5. 固定问题与聚合

每品牌核心 40 题：30 题非品牌品类/场景/约束题、5 题竞品比较、5 题品牌事实。10 题探索集独立运行。题目、题型、目标地区、语言发生变化时创建新版本。

每题先算指标，再对固定题等权平均；例如两题推荐率分别为 1/2 和 3/3，题均值为 75%，池化明细为 4/5=80%，必须展示标签，不能互相替换。若固定题有一题完全缺数，总览显示“部分覆盖”，同时显示已覆盖题数；前后比较仅使用双方有足够样本的共同题，并列出剔除题。

用于阶段验收的比较默认要求：总体 E/P≥90%，每题每窗合格槽位覆盖≥80%，至少覆盖预先冻结非品牌题的 80%；低于门槛只展示探索观察。以上为设计阈值，阶段 0 可调整并冻结，不能见到结果后放宽。质量门槛与运营目标 V/P≥95% 是不同指标。

推荐率变化使用百分点：20%→30% 为 +10 个百分点，相对变化 +50%；基线为 0 时相对变化不可定义。默认报告绝对变化、题数、样本数与未知比例。置信区间采用按问题/日期聚类的方法并记录实现；未实现时不展示虚构区间或“显著提升”。

## 6. 可手算验收例

1. 某一题计划 10 次，2 次超时，1 次有效但未满足联网条件，其余 7 次合格。V/P=8/10，E/P=7/10。7 次中 1 次推荐含义不明、3 次推荐、3 次不推荐，推荐率=3/6，未知=1/7。
2. 上例 7 次合格回答中，5 次引用信息完整可观察，包含 1 次完整空列表；其中 2 次有自有引用。自有页面引用率=2/5，引用可观察覆盖=5/7；不是 2/7，更不是把缺字段算作 0 条引用。
3. 同题同窗品牌甲有 3 条确认提及、品牌乙有 5 条，某些回答同时提到两者。甲 SoV=3/(3+5)，回答内甲重复三次仍只计一次。
4. 固定清单 20 页，完整覆盖的日志中 6 页有已核验爬虫访问，观测覆盖=6/20。若日志只覆盖一个节点，必须注明局部范围，不能报告“全站仅 30% 被抓取”。
5. 10 个可识别 AI 引荐会话中 2 个各提交两次相同咨询，按事件键去重后、按会话计算转化率为 2/10；四次提交不是四个客户。跨会话客户去重只有在获得合法、明确关联键时进行。

## 7. 质量与状态验收

至少 200 条标注样本覆盖别名、同名、否定、比较、虚构链接、无序列表、无引用与截断。留出不参与规则调优的验收集；两名复核人对争议仲裁，记录类别分布。建议门槛：实体精确率≥95%、召回率≥90%、原生引用解析准确率≥98%。少量引用的通道必须补足测试记录，不能将 0 条错误写成无限可靠。

实体精确率=TP/(TP+FP)，召回率=TP/(TP+FN)。引用解析以“样本 ID、引用来源类型、规范化 URL、引用标识/位置”组成的标注记录核对，版本化规则允许协议不提供位置；引用解析准确率定义为 TP/(TP+FP+FN)，另列精确率与召回率。重复引用按该协议的标注单位处理，规范化规则在验收前冻结。验收集缺少正例时指标为 N/A，不视为通过。

状态必须区分：无计划、待执行、失败、有效未合格、合格未判断、确认未提及、引用为零、引用不可观察、页面正文不可得。重试改变执行状态，不增加计划分母；纠错改变分析版本，不重写历史报告。

报告导出必须包含：样本范围、题集和通道、分子分母、聚合方式、缺数/排除列表、比较窗口、原文链接、发布版本、混杂因素与结论等级。不得导出令牌、私有事实或未授权租户内容。
