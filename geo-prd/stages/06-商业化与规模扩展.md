# 阶段 6：商业化与规模扩展

计划时间：八周试点之后，按门禁分批排期｜门禁：G6｜负责人：产品/商业负责人、技术负责人｜前置：[G5a/G5b](05-复测归因与试点验收.md)。

## 目标与进入条件

把已经验证的交付流程变成有范围、有价格、有成本控制的持续服务。G5a 后可准备报价和经营配置；扩大客户数、引入新渠道或重构架构前，需要 G5b 的观察结论与真实经济性支持。

输入：至少 3 家完整试点记录、客户反馈与付款/续费状态、单位成本分布、渠道故障数据、交付工时、待解决问题。不以 Star、注册量、文章量或短期推荐率单点变化替代经营证据。

## 套餐与服务边界

监测版提供固定问题、通过验收的通道、原始证据与报告；增长版增加事实维护、内容任务、审核和实验；代理商版增加多客户协作与配额；企业专属环境单独评估部署与支持成本。报价必须说明人工服务量，不能让软件订阅承担无限编辑、客服和发布工作。

供应商成本按所有实际调用核算，包括失败和重试；客户计费按套餐约定独立计算。客户账单、供应商费用和内部人工台账使用可关联事件，支持冲正与争议核对。退款、自动续费和支付渠道能力另行明确，不作为本阶段默认已实现功能。

单品牌月贡献 = 实际确认收入 − 监测/分析/搜索直接成本 − 抓取存储分摊 − 内容/采样/支持人工 − 渠道直接成本。该值不是公司净利润；研发、销售、管理等固定开销另算。一次性建档成本与持续交付成本分别展示，避免把接入月亏损或促销误判为常态。

经营目标必须在扩大投入前冻结，例如最低付费客户数、续费观察周期、持续贡献率下限、每品牌人工上限、获客成本回收期。当前没有真实数据，因此不预填“已达到”或虚构价格；缺少目标值时 G6 保持待评审，不影响继续完成既有客户合同交付。

## 扩展排序

优先选择能减少持续工时或满足已付费客户高频需求的功能。每个新增连接器算清实施、授权、平台改版、客服和停机的维护成本。没有可用权限时继续人工素材包；没有真实日志输入时不投入实时采集基础设施。

多站点能力仅在每个站点有独立业务目的、可验证事实和维护人时进入范围。站点数不等于优化价值；不靠大批同质站点制造“信源广度”。内容簇去重、事实一致性、审批和效果观察同样适用。

## 容量演进与架构触发条件

| 观察到的问题 | 先做的改进 | 才考虑的结构变化 |
| - | - | - |
| 引用页面重复抓取、费用偏高 | URL 去重、缓存、内容 hash、优先级抓取 | 独立抓取服务或浏览器池 |
| 报表查询变慢 | 索引、分页、预聚合、冷热分层 | 专用分析存储；需真实负载支持 |
| 任务积压或租约冲突 | 限流、公平调度、批量领取、增加 Worker | 专用队列；保留幂等和租户边界 |
| 单一模块 CPU/内存成为瓶颈 | 分离进程、限制并发、缩小输入 | 将该模块独立服务；不先重写整个系统 |
| 运维部署成本高 | 固定版本、恢复流程、观测与自动化部署 | 编排平台；需团队具备运维能力 |
| 团队有明确 Go 能力或部署约束 | 对单一模块做 Go PoC 并比较总成本 | 选择 Go 实现；通过迁移与回滚验收再替换 |

按主报告假设，100 品牌每月约 72 万计划样本；这是负载输入，不是已证明容量。压测需覆盖供应商限流、失败重试、队列峰值、报告并发和恢复，不能只测数据库插入。浏览器采集和截图单独计资源，不能据域名数直接算服务器数。

## 经营与质量看板

经营指标：付费品牌、实际确认收入、续费状态、套餐使用率、直接贡献、人工工时、客户阻塞天数、支持工单。观察周期尚未覆盖续费日时填“未到续费”，不能填未续费或已留存。

质量指标：V/P、E/P、引用可观察覆盖、人工复核待办、渠道故障、队列延迟、单位合格样本成本、发布 unknown 数、报告追溯成功率。可见度指标继续按通道和固定题展示，不汇成一个不可解释的全网分数。

## G6 与发布批次

G6 通过要求：冻结的经营目标达到；已有客户能按承诺完成持续交付；单位成本及人工可控；新增容量级别通过压测与恢复；新增渠道有独立验收和维护人。若经营目标未达到，先调整行业、套餐或交付方式，不自动扩容。

本阶段建议以 2—4 周为一个独立批次，但每批只选择少量可验收工作包，工期按真实积压和团队容量重估。商业功能、自动发布、日志连接器与 MCP 不要求同时完成。报价不代表对外签约授权，具体客户合同另按实际业务流程处理。

交付物：套餐与报价表、客户经营台账、成本与续费报告、连接器验收、容量计划、版本及许可证记录、运行手册、G6 决策。每次扩展保留上一版本回滚路径和报告复算能力。

## 持续运营交接

G6 后由交付负责人维护客户周期与待办，技术负责人维护渠道版本、故障响应和恢复，商业负责人维护报价与续费。每次月度评审把新增需求转成下一批工作包，指定负责人、预算、验收和停止条件。渠道失效或成本超限时先暂停受影响计划并说明覆盖变化；客户数据删除、账号撤销和合同退出按既定流程完成，不能留下无人负责的连接器和后台任务。
