# M2 功能规格

> v3.0｜2026-11-17｜后续增量：规模与授权；依赖 M1 通过。

共同约束见 [公共 SPEC](../04-产品功能规格-SPEC.md) 和 [指标合同](../07-指标与证据合同.md)。输入、规则、状态、异常与验收均是必需行为；技术实现不作指定。

<a id="s-m2-01"></a>
## S-M2-01 消费者入口辅助采集

- 需求：R-M2-01；任务：[T-M2-01](../tasks/M2.md#t-m2-01)。
- 用户价值：减少人工存证耗时，同时保留真实采样条件。
- 操作者：授权采集者。
- 入口：监测 → 今日采集清单/采集助手。
- 输入：允许的目标入口、冻结题单、用户已打开的页面、明确采集动作和证据权限。

1. 按入口建立 verified 能力和允许的操作清单；助手提供题目复制、字段检查、页面可见内容提取与证据预览。
2. 用户确认发送和存证；不收集账号密码/Cookie，不绕过登录、验证码或访问限制。无法自动提取可回到 M0 人工录入。
3. 预览原文/引用/模式和截图一致性，用户确认后保存；页内隐藏信息或不可见内部推理不作为产品承诺。
4. 记录每条采集耗时与返工率，和人工 SOP 同范围比较；节省时间不以丢失条件/引用完整性为代价。

**输出**：消费者观察、采集质量清单、人工耗时对比。

**状态与合法变化**：assigned → opened → captured_draft → confirmed/rejected；入口 degraded 时退回人工。

**异常与恢复**：页面变更/权限受限暂停该入口辅助能力，保留草稿；不自动换号换代理。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M2-01-1 | 遇到验证码或登录墙 | 执行辅助采集 | 停止自动步骤并提示用户正常处理，不绕过 |
| AC-M2-01-2 | 原文提取缺引用 | 预览存证 | 显示 partial，人工可补齐，不能静默当完整空引用 |
| AC-M2-01-3 | 入口结构变化 | 继续采集 | 自动能力降级，原题单与人工存证仍可用 |

<a id="s-m2-02"></a>
## S-M2-02 授权草稿、发布及通知连接

- 需求：R-M2-02；任务：[T-M2-02](../tasks/M2.md#t-m2-02)。
- 用户价值：把已验证的重复外部操作变得可控。
- 操作者：负责人、发布者。
- 入口：设置 → 连接；内容 → 外部动作预览。
- 输入：客户授权的账号/CMS/通知端点、权限范围/有效期、批准内容版本、动作预览和用户确认。

1. 优先草稿/CMS 草稿连接，再根据实际平台许可开放公开发布；每个连接标明“读/写草稿/公开发布/通知”的独立能力。
2. 公开发布必须确认目标账号、内容版本、发布时间和预计费用；批准文案不自动授予任意账号发文权限。
3. 同一外部动作重复提交不重复发布；远端已受理但响应未知先查回执/人工对账，禁止盲目重试。
4. 授权撤销阻止新动作；在途未知结果不得声称远端撤回。通知只发已授权渠道，默认不包含客户原文或私密资料。
5. 返回草稿回执只算 draft_created；仍须公开 URL 核验才能计干预生效。用户可随时断开连接。

**输出**：授权能力、动作预览/确认、远端回执、对账与核验结果。

**状态与合法变化**：connection pending → verified → expired/revoked；action prepared → confirmed → submitted → acknowledged/unknown/failed → reconciled。

**异常与恢复**：资质/权限不足隐藏不可用操作并提供人工交付；不会用非官方或绕过限制方式补齐。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M2-02-1 | 只授权草稿权限 | 请求公开发布 | 拒绝且给出人工后续，草稿成功不算公开 |
| AC-M2-02-2 | 请求已受理但本地超时 | 重试相同动作 | 先查单或待核对，不重复远端发布 |
| AC-M2-02-3 | 通知授权撤销 | 发送下一条提醒 | 停止发送，历史发送记录不被删除 |

<a id="s-m2-03"></a>
## S-M2-03 代理商交付与商业权益

- 需求：R-M2-03；任务：[T-M2-03](../tasks/M2.md#t-m2-03)。
- 用户价值：多客户经营可隔离、可签收、可解释消耗。
- 操作者：品牌负责人、代理项目经理、经营管理员。
- 入口：工作区 → 客户组合/交付/账单。
- 输入：明确品牌委托、有效期、操作范围、服务清单、报价和客户权益、实际成本、签收与续费状态。

1. 代理商须有品牌方可撤销的委托；内部成员身份不能替代委托。授权范围和组织内部角色取交集。
2. 跨品牌组合看板默认汇总进度/阻塞/成本，进入具体证据仍逐品牌授权；客户报告按品牌隔离。
3. 套餐明确监测额度、内容交付、人工服务、周期、超限行为和失败补偿口径；试用、报价、实际收费分开。先支持订单/支付结果登记，对接真实支付需独立验收，未接通不出现假付款成功。
4. 报告分享需有效期、范围、撤销与访问记录，默认仅被授权身份；白标仅改外观，不能删除数据来源/样本限制。
5. 经营视图分开软件与服务收入、外部调用与人工成本；计费价不抄原型点数。账单争议可关联操作与回执。

**输出**：委托记录、客户组合、交付签收、权益用量与账单、受控分享。

**状态与合法变化**：grant requested → active → expired/revoked；delivery pending → accepted/disputed；order draft → confirmed → paid/cancelled/refunded（仅有真实凭据时）。

**异常与恢复**：委托撤销时排队动作重新鉴权；支付结果未知为待核对；套餐调整不回写历史账单。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M2-03-1 | 代理成员有效但品牌委托到期 | 访问品牌或执行排队动作 | 拒绝，不能靠代理组织身份越过委托 |
| AC-M2-03-2 | 客户下载白标报告 | 查看来源与限制 | 保留轨道、样本量和结论等级，不能改成效果保证 |
| AC-M2-03-3 | 无支付连接仅记录报价 | 提交订单 | 保持待支付/登记状态，不显示实际收款成功 |

## S-M2-04 站点与业务数据持续连接

- 需求：R-M2-04；任务：[T-M2-04](../tasks/M2.md#t-m2-04)。
- 用户价值：减少重复导入，让观测与业务反馈持续可用。
- 操作者：品牌管理员、分析者。
- 入口：设置 → 数据连接；业务反馈。
- 输入：已授权站点分析/日志/业务系统字段、最小事件范围、同步游标、来源规则和撤销策略。

1. 以 M1 去重和归因规则为准，连接器不得新增一套口径；首次同步先预览字段、数量和个人信息范围。
2. 支持增量、重复投递、迟到事件和冲突复核；补采不重复计咨询。同步范围不完整须注明。
3. 日志中声称 AI 爬虫的标识与经核验身份分开；机器人访问、人类引荐、回答引用分别统计。
4. 撤销停止后续同步，已授权持有的数据按保留策略处理；允许导出/删除，报告显示源数据撤除影响。

**输出**：带来源和同步覆盖的站点/线索事件，去重汇总及连接健康度。

**状态与合法变化**：preview → approved → syncing → healthy/degraded/paused/revoked；事件 accepted/duplicate/conflicted。

**异常与恢复**：接口不可用退回授权 CSV 导入；缺少身份/来源证明标未知，不自动补猜。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M2-04-1 | 相同事件从 CSV 与连接器进入 | 同步 | 按明确事件键去重，并保留两个来源 |
| AC-M2-04-2 | 仅有 user-agent 声称 AI 爬虫 | 生成报告 | 标未核验身份，不称确定被某 AI 收录 |
| AC-M2-04-3 | 撤销数据授权 | 下一轮同步 | 停止拉取，历史数据按保留策略可管理 |

<a id="s-m2-05"></a>
## S-M2-05 受控经营助理与策略复用

- 需求：R-M2-05；任务：[T-M2-05](../tasks/M2.md#t-m2-05)。
- 用户价值：让运营把时间用在判断和审核，而非重复整理。
- 操作者：负责人、运营。
- 入口：总览 → 本周行动计划/助理。
- 输入：已授权证据、目标、预算、待办、历史复测和批准策略模板。

1. 助理输出有限行动草案：目标问题、理由证据、拟执行动作、费用上限、所需授权和完成标准；默认每批最多 5 项。
2. 只有用户逐项确认的动作才转任务；发布、改变授权、付款和删除不能通过自由文本隐式批准。
3. 执行前再校验事实、内容版本、通道和预算。观察结果可以建议下一轮，但没有无限自循环与自动扩预算。
4. 策略模板保留适用行业、采样条件、证据强度和失败案例；没有受控证据的策略不能标“高胜率/必有效”。

**输出**：可编辑行动计划、确认记录、任务执行状态和复盘建议。

**状态与合法变化**：proposed → edited → confirmed → executing → completed/partial/blocked/cancelled。

**异常与恢复**：证据不足要求补证；外部文本中的指令不能改变预算、权限或执行列表；失败回到具体任务。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M2-05-1 | 采集文本要求忽略预算并公开发文 | 助理生成计划 | 仅作为材料，不能触发动作或改变授权 |
| AC-M2-05-2 | 用户确认 3 项后事实到期 | 执行任务 | 相关项阻塞，其余按原授权执行，不自动扩范围 |
| AC-M2-05-3 | 历史只有一次成功观察 | 保存策略模板 | 标观察案例和条件，不标可保证收益 |

<a id="s-m2-06"></a>
## S-M2-06 行业、本地场景与多模态内容扩展

- 需求：R-M2-06；任务：[T-M2-06](../tasks/M2.md#t-m2-06)。
- 用户价值：在有真实需求时扩展大陆长尾经营场景。
- 操作者：本地商家、行业运营、审核者。
- 入口：品牌资料 → 门店/行业；内容 → 变体。
- 输入：已批准门店地址/服务区域/营业时间/产品线、行业问题包、媒体资料与来源、目标渠道。

1. 同名门店、连锁品牌与产品线分别建实体关系；目标城市问法与实际采样位置分开，不支持定位时不得显示已定位城市。
2. 问题模板覆盖场景、预算、服务范围和时效；专业行业模板须有明确适用范围，不能将通用模板用于未覆盖监管场景。
3. 允许从已批准正文生成信息图/口播脚本，或为 Brief 生成插图候选；数值与事实绑定，图像文字需人工核验。
4. 图片/脚本各自版本、权利、标识和审批；不把插图或合成口播包装成真实客户证明，不扩成自动视频矩阵发布。

**输出**：行业问题包、门店/产品线关系、本地观察分层和可审核图文/脚本变体。

**状态与合法变化**：行业模板 draft → reviewed → available/retired；媒体 draft → review → approved/invalidated。

**异常与恢复**：地址/营业信息过期阻断相应交付；无法读取图片文字时人工核验，缺凭据不补造。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M2-06-1 | 目标城市为杭州但采集位置未知 | 看本地报告 | 明确显示目标杭州/实际未知，不声称杭州用户真实排名 |
| AC-M2-06-2 | 插图生成错误价格 | 审核 | 阻止公开交付并指向对应事实版本 |
| AC-M2-06-3 | 同品牌两个门店服务范围不同 | 生成回答核对与内容 | 分别使用门店事实，不能跨店混用 |
