## S-M0-01 自助入口、品牌建档与资源归属

- 需求：R-M0-01；任务：[T-M0-01](../tasks/M0.md#t-m0-01)。
- 用户价值：降低首次启动门槛，让小 B 经营者直接开始。
- 操作者：访客、品牌负责人。
- 入口：首页 → 品牌引导 → 设置。
- 输入：身份；品牌名（2–80 字）、一句话业务（5–300 字）、目标地区（默认中国大陆）、语言（默认简体中文）；官网可空；别名 0–10 个、竞品 0–3 个可跳过。

1. 引导分品牌、关注范围、问题三步；保存草稿，返回不丢失；M0 每个负责人默认 1 个活跃品牌。
2. 中文全称/简称去首尾空白，保留用户输入；同名品牌不全局合并。官网只接受公开 HTTP(S) 地址。品牌资料变更不覆盖历史报告的实体版本。
3. 无官网允许继续，官网引用显示不适用；用户可登记自有公开页面及归属证据。无可用通道时可建档但不能启动监测。
4. 所有品牌、事实、任务、证据、导出受资源归属约束；成员/代理协作在后续级别。删除品牌先展示影响，确认后进入删除流程；未清偿费用与保留记录按公共合同处理。

**输出**：品牌档案与实体版本、可继续的引导草稿、真实可用渠道入口。

**状态与合法变化**：draft → active → archived；archived 可恢复；删除为独立受确认流程。

**异常与恢复**：会话失效保留非敏感草稿；官网无效定位字段；额度限制说明可归档品牌；越权只显示资源不可用。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-01-1 | 未填官网且竞品为空 | 填品牌、业务和地区并完成引导 | 品牌可保存，官网引用为不适用，不伪造官网 |
| AC-M0-01-2 | 另一个用户持有品牌/证据/导出标识 | 访问或修改这些资源 | 拒绝且不泄漏内容；下载也受相同限制 |
| AC-M0-01-3 | 品牌已存在历史样本 | 修改别名和退出再进入引导 | 新实体版本生效，旧报告仍引用旧版；草稿恢复 |

## S-M0-02 轻量品牌事实与补证

- 需求：R-M0-02；任务：[T-M0-02](../tasks/M0.md#t-m0-02)。
- 用户价值：先确认事实，再产出可公开内容。
- 操作者：品牌负责人。
- 入口：品牌资料 → 事实与材料。
- 输入：结构化字段或整段粘贴（单次最多 20,000 字）；来源 URL/材料说明、出处片段、公开许可、有效期；可先保存缺项草稿。

1. 结构化录入覆盖产品定位、功能参数、价格条件、服务区域、资质案例、适用/不适用边界。粘贴抽取只产出候选，必须预览、拆分和逐条确认。
2. 确认事实必须有可定位来源、来源时间、可公开范围和有效期或明确长期有效。长期有效默认 180 天提醒复核；价格默认 30 天提醒复核，不把提醒当外部事实失效日。
3. M0 允许负责人确认本人录入的事实，但必须独立点击确认，AI 不可自行确认。内部资料可支撑判断但原附件不可随内容包公开。
4. 缺来源、相互冲突、不可公开的核心主张生成补证项；过期/撤销事实阻断新交付，并列出受影响内容。采样监测不接收此事实库。

**输出**：FactVersion、来源片段、确认记录、缺材料待办和受影响内容列表。

**状态与合法变化**：draft → pending_confirmation → approved → expired/revoked；修订建立新版本；冲突候选不覆盖批准版。

**异常与恢复**：抽取失败保留原输入并允许手工拆卡；来源受限可附用户授权说明但仍标明不可外查；不强制上传敏感材料。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-02-1 | 粘贴的资料包含无来源参数 | 请求确认该参数 | 阻止批准并给补证动作，原文仍可保存 |
| AC-M0-02-2 | 有已批准可公开事实和内部附件 | 生成内容后撤销该事实 | 未交付稿件标失效，受影响版本列出；原附件不进入公开包 |
| AC-M0-02-3 | 已批准一版价格 | 录入不同的新价格 | 创建待确认版本并提示冲突，不覆盖旧报告和旧审批 |

## S-M0-03 购买问题簇与题集预览

- 需求：R-M0-03；任务：[T-M0-03](../tasks/M0.md#t-m0-03)。
- 用户价值：用客户真实问题组织监测和内容。
- 操作者：品牌负责人。
- 入口：品牌资料 → 监测问题。
- 输入：手工输入/逐行粘贴/候选生成；问题文本（5–500 字）、来源、题型、购买阶段、目标地区/语言；最多 10 个快速核心题。

1. 默认给 6 个可编辑非品牌候选；启动至少 3 个确认问题，其中至少 3 个为非品牌发现/场景/约束题。比较题和品牌事实题可另加，总数不超过 10。
2. 候选须展示生成来源或真实咨询来源（脱敏），不捏造搜索量。规范化空白后完全重复阻止保存，语义近似只提示，用户决定保留。
3. 包含目标品牌名、别名或竞品的题不能计入非品牌自然发现主指标；诱导推荐、指定答案的提问显示风险，转为探索题，不作自然发现。
4. 每题归入一个主要购买问题簇；问题簇保存受众、意图、主页面（可待补）、承接动作（可待补）。启动快测不强制主页面，创建内容 Brief 时必须补齐。
5. 运行冻结题目版本、类型、范围和采样重复数；编辑只创建新版本，历史题不得覆盖。问题从未被引用可删，否则只能停用。

**输出**：确认题集版本、分类计数、问题簇、预算预览输入。

**状态与合法变化**：candidate → confirmed → frozen-in-run；修改后新版本；可停用。

**异常与恢复**：全部重复或全部诱导题不能启动自然发现监测；人工题可用，AI 生成不可用不阻塞手工建题。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-03-1 | 有 3 个非品牌问题和 1 个带品牌比较题 | 预览并启动 | 共 4 题保存，主指标仅用 3 个非品牌题 |
| AC-M0-03-2 | 输入重复空白变体和语义近似题 | 确认候选 | 完全重复被拦，近似题可人工保留且显示提醒 |
| AC-M0-03-3 | 已有一个冻结题集 | 编辑其中一题再复测 | 产生新版本，可比性明确排除变更题，不覆盖旧问题 |

## S-M0-04 真实通道能力台账与双轨采样范围

- 需求：R-M0-04；任务：[T-M0-04](../tasks/M0.md#t-m0-04)。
- 用户价值：明确数据来自什么对象，防止 API 冒充消费者产品。
- 操作者：负责人、能力维护者。
- 入口：设置 → 监测能力；运行确认页。
- 输入：渠道名称、consumer_ui/model_api/custom_pipeline、产品入口、模式、模型版本或 unknown、可用性、联网/引用/地区能力、验证时间和限制。

1. M0 上线需至少 1 个官方 API 真实路径，以及 1 个消费者入口人工采样 SOP；API 报告和消费者观察分开展示。
2. 能力状态为 candidate、verified、degraded、disabled；仅未过期的 verified 可新建正式计划。默认验证有效期 30 天；显著行为变化立即失效。
3. search_required 是布尔采样门槛；记录请求的联网模式（on/off/unknown）与实际触发证据，实际联网是 true/false/unknown；配置开关开启不等于已触发。
4. 引用能力支持 complete/partial/unsupported；页面品牌标志不构成平台接入证明。目标地区可配置但实际地区未知时如实标注。
5. 无验证可使用演示空间；真实用户手工提交的材料可保存为待核验，不宣称平台已支持自动采集。

**输出**：可选渠道卡、限制说明、能力验证记录及版本；API/C 端各自范围快照。

**状态与合法变化**：candidate → verified → degraded/disabled；重新验证产生新版，不能修改旧报告口径。

**异常与恢复**：能力过期或停用阻止新计划，已有证据仍可查看；在途采样标清变化，不自动切到别的供应商混算。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-04-1 | API 与消费者入口名称属于同一厂商 | 查看选择器和报告 | 显示两种独立来源，不能合成一个品牌推荐率 |
| AC-M0-04-2 | 渠道未验证或已过期 | 请求新运行 | 阻止正式执行并说明原因，不能返回模拟成功 |
| AC-M0-04-3 | 接口配置了联网但无触发证据 | 保存回答 | 实际联网为 unknown，不能进入 required 联网合格分母 |

## S-M0-05 监测运行、进度与预算

- 需求：R-M0-05；任务：[T-M0-05](../tasks/M0.md#t-m0-05)。
- 用户价值：让用户知道测了什么、成功多少、消耗多少。
- 操作者：品牌负责人。
- 入口：监测 → 新建运行/运行详情。
- 输入：冻结题集、通道、采样条件、重复数（默认 1，M0 可选 1–3）、时间、用户确认的费用/配额上限。

1. 提交前展示问题数×通道数×重复数、预计费用区间及待核实部分；每个轨道单独确认。供应商成本和用户额度分开，免费体验不等于供应商免费。
2. 每个计划槽位只计一个被采用结果。尝试记录保留，重试不增加计划分母；重复提交同一动作不重复创建或扣额度，变更输入须新动作。
3. 支持部分成功、暂停、继续、取消；暂停/取消停止尚未执行的单元，在途结果保留并标明。刷新页面可恢复进度。
4. 最多 2 次额外尝试，仅对明确未执行或可安全重试失败；供应商受理结果未知进入 reconciliation_required，不盲目重复付费调用。
5. 运行前和每个付费单元执行前检查硬预算；没有可信费用上界的真实通道不能自动运行。分析失败可用原回答重做分析，不再付费采样。

**输出**：Run、Slot、Attempt、原始回答、已完成/失败/待执行数量、实际/预留/待核对费用。

**状态与合法变化**：queued → running → succeeded/partial/failed/cancelled；running ↔ paused；单元另有 reconciliation_required；终态后重试创建关联修复动作而非抹掉历史。

**异常与恢复**：额度不足给调整问题数/重复数动作；限流显示稍后重试；未知费用保持预留，待核对后结算/释放；不把失败算未提及。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-05-1 | 同一请求连续提交 3 次 | 查看任务与额度 | 只有一个运行和一组槽位，同输入返回原结果；换输入不能静默复用 |
| AC-M0-05-2 | 4 槽位中 1 个超时且费用未知 | 运行结束 | 显示 3 个结果和 1 个待核对，P 仍为 4；不立即重复远端请求 |
| AC-M0-05-3 | 预算只够 1 个单元 | 同时启动两个单元 | 仅一个执行，另一个暂停；分析重试不新增采样费用 |

## S-M0-06 回答证据、人工存证与独立判定

- 需求：R-M0-06；任务：[T-M0-06](../tasks/M0.md#t-m0-06)。
- 用户价值：每一个结果都能看原文和纠正误判。
- 操作者：负责人、人工采集者。
- 入口：AI 回答 → 原文详情/人工录入。
- 输入：问题/通道/时间/模式/新会话条件、目标及实际地区、回答原文、引用可见状态、消费者截图或可定位存证、采集人；实体版本。

1. 消费者人工记录缺字段可保存草稿，完整后才参与 V/E；截图需对应原文，存在冲突进入待复核。不得收集第三方账号密码或会话凭证。
2. 原文只追加，修改误录保留修订关系；标签纠错只追加 analysis_version。提及/推荐/官网引用分别 true/false/unknown；推荐需有满足问题需求的明确语义。
3. 原生引用保留来源标识和可见位置。搜索候选、模型正文中的猜测链接、分析师找到的页面分别归类，不计原生引用。完整空引用属于可观察，缺字段不是空引用。
4. 官网域名/子域名须经用户确认归属；共享平台账号或具体页面单独确认。引用存在与页面可访问/支持品牌分别记录。
5. 判定说明保存证据片段，否定推荐、同名歧义与引用不可观察不能被乐观推断。可见推理摘要仅作外部可见材料，不叫内部思考链。

**输出**：不可变 Observation、引用记录、独立分析版本、人工纠错及缺失说明。

**状态与合法变化**：draft_evidence → complete/incomplete/contested；分析 pending → classified/needs_review → revised；不覆盖原文。

**异常与恢复**：原文截断不入 V；引用页受限仍保留原生引用，但支持性为 unknown；截图包含个人信息先脱敏且不抹去必要判定上下文。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-06-1 | 回答说“甲可考虑；乙不适合本需求”，并引用乙官网 | 分析乙 | 提及=true、推荐=false、官网引用=true，三个结果独立 |
| AC-M0-06-2 | 一个完整空引用和一个缺引用字段回答 | 统计引用 | 前者进 C 且未引用，后者不进 C 且显示未知/不支持 |
| AC-M0-06-3 | 用户纠正同名误判 | 保存分析修订 | 原文不变，新 analysis_version 可见，既有报告仍引用旧版本 |

## S-M0-07 可解释概览与证据下钻

- 需求：R-M0-07；任务：[T-M0-07](../tasks/M0.md#t-m0-07)。
- 用户价值：普通用户理解结果和限制，找到下一步。
- 操作者：品牌负责人。
- 入口：总览、AI 回答列表。
- 输入：品牌、时间窗、轨道、通道版本、题型、地区、问题簇及分析版本策略。

1. 主卡为非品牌题的提及率、推荐率、官网引用率，附题等权说明、逐题分子分母、覆盖率和未知比例；自有平台页引用单独明细。
2. 所有图表和下钻使用同一过滤范围；不跨 API/消费者端、联网条件或不同协议版本平均。M0 不出综合分，不将无序列表解释为排名。
3. 无数据为 N/A，单条失败不变成 0%。快速报告默认显示“小样本观察”；图中给每窗题数/样本数，条件变更处分段。
4. 首页展示最多 3 条优先建议、进行中任务和阻塞；设置页承载额度。返回列表保留筛选与位置；保存草稿不依赖多标签页。
5. 简体中文、浅色高对比正文；375/768/1440 宽度主流程可用；键盘可到达操作，状态不只靠颜色。营销页示例有演示标签，真实空间不得注入演示数字。

**输出**：指标视图、数据质量摘要、任务入口、带相同条件的原文列表。

**状态与合法变化**：empty/loading/ready/partial/insufficient/unavailable；不因未到齐而隐藏已有有效证据。

**异常与恢复**：零分母提示具体原因和补数据动作；分析待复核显示未知数量；通道退化显示最后有效采集时间。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-07-1 | 无有效样本 | 打开总览 | 显示 N/A 和启动/补采动作，不出现伪造分数或增长 |
| AC-M0-07-2 | 两题推荐为 1/2 与 3/3 | 查看概览并下钻 | 题均值 75%，池化明细 4/5=80% 单独标明；可定位 5 条样本 |
| AC-M0-07-3 | 切换消费者端/时间范围 | 看 KPI、趋势和列表 | 范围全部一致，API 数据不混入；窄屏及键盘仍可操作 |

## S-M0-08 证据诊断、页面检查与行动任务

- 需求：R-M0-08；任务：[T-M0-08](../tasks/M0.md#t-m0-08)。
- 用户价值：把观察缺口转成能完成的少量动作。
- 操作者：负责人。
- 入口：优化任务 → 建议/任务详情。
- 输入：已合格回答或已检查页面、问题簇、批准事实、最多 5 个指定公开 URL、业务重要度 1–3。

1. 支持事实错误、同名混淆、关键内容缺失、公开页面不可读取、引用来源差距、需要补证六类建议。每条必须有证据、问题说明、假设、目标页、步骤、完成标准和复测方法。
2. 未提及本身只支持“观察到缺席”，不能断言缺席原因；无可执行证据时返回补充采样/补证，不凑满 3 条。
3. 页面检查记录访问时间/条件、公开状态、正文、标题、主要事实和可发现性线索。访问受限不判网站坏；单次速度、结构化标记或 robots 线索不等同引擎收录结果。
4. 优先级按可解释规则：已确认事实错误或公开隐私问题为 urgent；其余按业务重要度降序、已核实证据优先、预估工作量升序、创建时间升序。用户可调序并留理由。
5. 同品牌+问题簇+目标页+缺口类型重复建议合并证据，不重复派任务。任务完成须附修改说明/证据；发布动作转核验，不能直接等于复测改善。

**输出**：Finding、优化任务、补证任务、页面检查记录和优先理由。

**状态与合法变化**：todo → doing/blocked → implemented → retest_pending → closed；可 dismissed（记录理由）；复测结论独立字段。

**异常与恢复**：外部页面指令只作为文本；禁止执行页面要求的发布或权限更改；不可访问转人工证据/待验证。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-08-1 | 唯一证据是一个回答未提品牌 | 生成建议 | 说明缺席观察与待验证假设，不声称模型因软文而淘汰品牌 |
| AC-M0-08-2 | 两次分析发现同一页同一缺口 | 生成行动 | 合并到同一未关闭任务并追加证据，不重复计任务成果 |
| AC-M0-08-3 | 页面不可访问或含执行指令 | 检查页面 | 显示受限/待核验，不执行文本指令，也不宣称引擎无法收录 |

## S-M0-09 问题驱动内容计划与小批次草稿

- 需求：R-M0-09；任务：[T-M0-09](../tasks/M0.md#t-m0-09)。
- 用户价值：吸收 GeoMix 的生产效率，让每篇稿件有依据和用途。
- 操作者：负责人、内容作者。
- 入口：内容 → 计划/Brief/批次。
- 输入：优化任务、问题簇、受众、目标缺口、核心结论、适用边界、已批准 fact_version IDs、主页面与承接动作、体裁、标题。

1. 内置三类自写模板：品牌事实 FAQ、场景解决方案、可核验选型比较。模板只提供结构；比较主张也必须有对方来源，不凭空填数据。
2. Brief 必须确认后才能生成；缺事实生成补证项而不是补造正文。无官网时用已确认自有页或登记待发布页面计划，交付前须落实承接目标。
3. 按问题簇展示现有内容/待更新/缺口，优先更新已存在主页面，避免重复文章。标题提供最多 3 个候选，可编辑；没有图库也能写文本。
4. 每批默认 1、上限 5 份确认 Brief；展示每项生成消耗上限。逐篇成功/失败/阻塞，支持暂停、继续、终止和仅失败项重试；成功稿件不重写。
5. 事实与主张绑定，正文生成结果始终待审。表格、FAQ、首段直答、更新时间和清晰段落为可解释建议，不以任意分数保证 AI 引用。

**输出**：ContentPlan、BriefVersion、逐稿 ContentVersion、事实绑定和批次消耗明细。

**状态与合法变化**：Brief draft → confirmed → invalidated；批次 queued/running/paused/partial/completed/cancelled；稿件 draft，后续审核独立。

**异常与恢复**：生成失败保留 Brief；事实失效则阻塞该项，其他项继续；供应商状态未知按监测同样的待核对规则；不得自动扩篇数。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-09-1 | Brief 缺来源或适用边界 | 请求生成 | 拦截并转补证，不能生成完整营销断言 |
| AC-M0-09-2 | 3 份 Brief 中 2 成功 1 失败 | 只重试失败项 | 成功版本不变，批次保留原记录，仅失败项新增尝试 |
| AC-M0-09-3 | 已确认 Brief 的事实被撤销 | 继续暂停的批次 | 受影响单元阻塞，其他单元可继续，生成物不能自动成为已批准 |

## S-M0-10 逐稿审核、素材与交付包

- 需求：R-M0-10；任务：[T-M0-10](../tasks/M0.md#t-m0-10)。
- 用户价值：可交付内容必须可追溯且适合目标渠道。
- 操作者：负责人、审核者。
- 入口：内容 → 稿件详情/审核/导出。
- 输入：内容版本、标题/正文/图片/目标页、事实绑定、图片权利声明、目标渠道（主页面+1 个外部渠道）、标识 profile。

1. 事实失效、无来源核心主张、不可公开内容、未审核图片或无有效内容批准为硬门禁；段落长度、表格等为建议。用户新增核心主张也须绑定事实。
2. M0 单人可显式自审，记录审核人与时间；生成不会自动批准。标题/正文/图片/事实版本/渠道/标识配置任一变更使该变体批准失效。
3. 附件可选：上传授权图片并说明来源/用途，封面与正文可独立选择，也可不用图；素材不能生成假资质或假案例。
4. M0 导出 Markdown/净化 HTML、公开事实来源清单、图片（如有）、manifest 和发布核对单；禁止内嵌私密附件、凭证和其他品牌内容。
5. 每份包绑定批准内容指纹、事实版本和标识规则。保留生成声明及适用文件标识；仅内部日志或 manifest 不替代文件本身应有标识。不提供去标识工具。
6. 批量导出先预检全部选中项；不通过项列明原因，用户明确选择仅导出合格项，不静默漏稿。生成包成功不计公开发布。

**输出**：Approval、不可变交付包、版本差异、逐项导出结果、可交付与待审核列表。

**状态与合法变化**：draft → in_review → approved/rejected → invalidated；导出另有 queued/ready/failed；旧包保留但失效时显示勿再使用。

**异常与恢复**：标识格式未验证只可导出审阅稿，带“非发布用”标记；富文本不执行脚本；归属未确认的图片移出公开交付。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-10-1 | 已批准内容改变一个标题字或图片 | 再次导出 | 旧批准失效，新版本须重审；旧文件和旧审批仍可追溯 |
| AC-M0-10-2 | 包含内部资料附件和公开事实摘录 | 导出正式素材包 | 仅输出允许公开的内容及来源说明，无内部附件与凭证 |
| AC-M0-10-3 | 批选 3 稿但 1 稿事实过期 | 导出 | 显示阻塞项并要求明确选择合格子集，成功数为 2 而非 3 |

## S-M0-11 人工发布回填与公开核验

- 需求：R-M0-11；任务：[T-M0-11](../tasks/M0.md#t-m0-11)。
- 用户价值：区分导出、提交和实际对公众生效。
- 操作者：负责人、发布者。
- 入口：内容 → 发布记录/核验。
- 输入：批准内容版本、目标账号/页面、实际 URL、发布者、用户申报时间、渠道声明确认、公开证据。

1. M0 在外部由用户自行发布；回填不是发布授权，不自动登录账号。草稿箱链接保持 draft_only。
2. 核验需公开可见且关键事实与批准版一致；仅 HTTP 成功码不够。login_required/access_limited 不按删除或发布成功处理。
3. 受限页可由人工提交可复查截图、页面标识、时间和关键正文对照；M0 标 verified_manual（单人核验），M1 团队开启双人规则后须另一人复核。该状态与 verified_public 区分显示。
4. effective_at 使用首次核验通过时间，用户申报发布时间单独保存；不得用导出或任务创建时间代替。内容明显删改为 mismatch，生成修复任务。
5. 每个发布版本单独记录；新版本确认后可替代旧版，但旧证据保留。平台撤下或事实失效时显示维护需求；是否恢复需再核验。

**输出**：PublicationVersion、核验结果、实际生效时间、证据及维护待办。

**状态与合法变化**：prepared → submitted → draft_only/pending_check → verified_public/verified_manual/mismatch/access_limited/removed；重核验追加记录。

**异常与恢复**：未知页面归属先确认；无法公开访问给人工复核入口；无有效审批拒绝核验为当前合格交付，允许保存异常记录。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-11-1 | 回填公众号草稿或登录页 | 核验 | 显示草稿/受限，无 effective_at，不计公开核验通过 |
| AC-M0-11-2 | 页面公开且关键事实一致 | 核验通过 | 保存核验时间为 effective_at，关联准确内容和审批版本 |
| AC-M0-11-3 | 用户手工提供受限页面的完整证据 | 确认核验 | 记录 verified_manual 和人工证据等级，不冒充匿名公开访问成功 |

## S-M0-12 同口径复测与报告快照

- 需求：R-M0-12；任务：[T-M0-12](../tasks/M0.md#t-m0-12)。
- 用户价值：验证执行后的变化，并诚实说明能比较到什么程度。
- 操作者：负责人。
- 入口：复测与报告。
- 输入：优化任务、核验生效内容、前后运行、冻结题集/通道/采样条件、分析版本、观察窗口、环境变化说明。

1. M0 提供立即复测（探索）与 D+7 提醒入口；提醒为站内待办，不自动增加付费调用。可在无内容动作时做诊断复跑，但不计经营闭环完成。
2. 比较必须按相同题版本、实体/竞品口径、通道版本、轨道、模式、地区条件、会话协议及可比分析规则匹配；共同题重算双方，列出排除项。
3. M0 至少 3 个共同非品牌题且各题双方有可判断样本才显示探索 pp；不足显示不可比较。M1 才允许满足正式质量阈值的阶段报告。
4. 输出 improved/unchanged/declined/inconclusive 是观察结论，不是因果；任务实施完成与观察结论分开，下降也可正常关闭并安排后续行动。
5. 报告保存纳入与排除样本清单、每题分母、版本、内容/发布时间、限制；HTML 与可复算 JSON 从同一快照导出。后续纠错生成新快照，不修改旧报告。
6. M0 下载需本人权限，无匿名分享；证据删除后旧快照标来源缺失，不能伪造原证据仍完整。

**输出**：Retest、Comparison、不可变 ReportSnapshot、HTML/JSON、下轮决策。

**状态与合法变化**：scheduled → due → running → completed/inconclusive/blocked；报告 created → superseded；不得手工把任务完成写成改善。

**异常与恢复**：通道变更或缺数列具体阻塞；窗口未到期只出阶段进度；手动核验内容在报告显式标出证据限制。

| 验收 ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-M0-12-1 | 前后有 3 个共同题和 1 个修改题 | 请求对比 | 只以 3 个共同题重算双方并标探索，列出排除题和覆盖 |
| AC-M0-12-2 | 用户完成改稿但尚未公开核验 | 请求经营闭环报告 | 允许诊断复跑，不能声称公开干预已生效或闭环完成 |
| AC-M0-12-3 | 报告已生成后纠正标签 | 重新出报告 | 旧文件与计算结果保持不变，新快照关联前版且分子分母可复算 |
