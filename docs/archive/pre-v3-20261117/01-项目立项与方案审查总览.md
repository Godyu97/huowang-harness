## 二、 原 `geo-prd` 方案深度审查报告

我们对仓库内原有的 17 份规划文档进行了全面交叉审计。总体而言，原方案在**数据真实性、反黑产合规意识、证据可追溯性与工程严谨度**上具备极高水准，但存在**文档碎片化冲突**以及**对中国大陆 AI 搜索独特生态落地不足**的问题。

### 2.1 原方案值得保留的 5 大核心资产（Keep）

1. **三类证据严格隔离**：将搜索候选（`SearchEvidence`）、API 模型回答（`ModelAnswer`）、真实消费者端观察（`ConsumerObservation`）物理分离，严禁混算成一个虚假的“全网 AI 综合排名分”。
2. **指标分母透明可复算**：区分计划槽位 $P$、有效回答 $V$、条件合格回答 $E$、可判断样本 $J_m/J_r$ 与原生引用可观察样本 $C$；缺失数据标 `N/A`，绝不将采集失败当作“0% 提及率”。
3. **品牌事实库（Brand Fact Vault）防幻觉机制**：监测请求绝不夹带客户私有事实库（防止污染测量结果）；内容生成强制绑定经审批的 `fact_id` 与有效期，事实过期自动阻断待发稿件。
4. **合规安全底线清晰**：拒绝收集客户平台明文密码、拒绝服务端共享 Cookie 池黑产群发、拒绝水军伪造百科与虚假用户测评，全面遵循《人工智能生成合成内容标识办法》。
5. **同构全栈工程选型务实**：采用 `Next.js + TypeScript Worker + PostgreSQL` 单语言 Monorepo 架构，避免了早期小团队同时维护前端 TS 与后端 Go/Python 两套领域模型的割裂成本。

### 2.2 原方案存在的 6 大关键问题与本次定制修正（Fix & Upgrade）

| 编号 | 原方案痛点 / 冲突诊断 | 结合大陆行业实战的定制重构方案 |
| :--- | :--- | :--- |
| **P1** | **多版补丁未合并，团队阅读认知分裂**<br>《初稿 v1.2》《效果导向修改建议》《SEO与14平台分发报告》《架构设计》各自表述一套页面、路由和流程，修订建议停留在纸面未合入主干。 | **建立五册合一规范体系**：废除补丁式文档，统一收敛为《立项总览》《PRD》《可行性调研》《开发 Spec》《资源与排期》五份正交文档及交互式 HTML 门户；统一 6 大业务模块与 URL 路由规范。 |
| **P2** | **忽视中国大陆“围墙花园”信源生态差异**<br>原方案偏重海外 GEO 思路（大量篇幅放在客户独立站 SEO 审计），忽略了国内公众号、知乎、百家号、头条/抖音生态对不同 AI 引擎的决定性权重。 | **定制“大陆引擎—信源亲和矩阵”与 `1+3+X` 策略**：以 **1 个高响应 SSR 事实官网**为锚点，首版打透 **微信公众号（攻元宝/Kimi）+ 知乎（攻 DeepSeek/豆包/Kimi/夸克）+ 百家号/头条（攻百度 AI/豆包）** 三大核心外部信源池。 |
| **P3** | **API 与真实 App 脱节，纯人工截图不可持续**<br>原方案指出 API ≠ 同名 App，但将 C 端核验退化为“纯手工复制粘贴截图”。每品牌 40 题跨 5 个平台手工采一次即需 200 次操作，交付人力必然崩溃。 | **首创“双轨三层”合规采集架构**：在 `L1 官方联网 API 自动高频监测` 与人工之间，新增 **`L2 桌面浏览器合规辅助采集插件（GeoPro Capture Extension）`**，在运营实名浏览器中半自动填词、一键结构化提取回答 + 思考链 + 引用卡片，大幅降低手工复制截图工时（具体提效倍数在 S0 实测确认），且不绕过平台验证、不共享账号。 |
| **P4** | **缺失推理模型“思考链（CoT）”归因分析**<br>2025-2026 大陆主流入口（DeepSeek-R1、豆包深度思考、元宝深度思考）均暴露详细推理过程，原数据模型只存最终回答，丢掉了最宝贵的淘汰原因。 | **新增 `Reasoning Trace（思考链诊断）` 管线**：结构化采集并解析大模型思考过程中的对比维度、采纳依据与淘汰槽点（如“未查到私有部署配置”、“疑似软文缺少客观数据”），直接转化为精准内容修改简报。 |
| **P5** | **AI 友好内容规范缺乏中文 RAG 工程细节**<br>原方案仅提出“回答-条件-证据-限制”框架，未针对中文大模型切片（Chunking）、实时抓取超时（1.5-3s）和反营销过滤做工程化约束。 | **制定《中国大陆 AI 友好内容工程六大黄金准则》**：语义自包含切片（每段带品牌与品类主语）、首屏 TL;DR 直答表、客观适用边界声明、权威信任锚点与新鲜时间戳、大陆 CDN < 1.5s 直出 HTML、合成内容显隐式合规标识。 |
| **P6** | **范围与排期严重倒挂（8 周塞入 120 人日工作量）**<br>原分发报告把 14 个平台模板塞进 P0（增 20-30 人日），叠加从零建多租户 RLS、队列、日志解析等，2 名开发在 8 周内绝对无法完成。 | **科学裁剪 MVP 范围并重排为 10 周里程碑**：首版砍掉非核心 10 平台模板与重型日志连接器，聚焦核心纵向闭环；明确 **标准版（4.5 FTE）** 与 **精简版（2.5 FTE）** 两套资源模型及 20% 风险缓冲。 |

## 三、 中国大陆 AI 友好型 GEO 业务闭环全景

GeoPro 围绕**“让品牌的真实优势在客户关键提问时刻被 AI 准确理解、可信引用并有效承接”**，构建六步闭环：

```mermaid
flowchart LR
    S1["1. 目标与建档<br/>客户成功计划 CSP<br/>品牌事实库 + 40核心题"] --> S2["2. 双轨采样监测<br/>L1 官方联网API日采<br/>L2 浏览器助手C端核验"]
    S2 --> S3["3. 思考链与信源诊断<br/>CoT淘汰归因分析<br/>官网可读性 & 竞品信源差距"]
    S3 --> S4["4. AI友好内容工程<br/>确认内容简报 Brief<br/>事实绑定创作 + 审批防错"]
    S4 --> S5["5. 1+3 亲和渠道分发<br/>官网SSR事实页更新<br/>公众号草稿直推 / 知乎百家号"]
    S5 --> S6["6. 四层复测与经营复盘<br/>D+7/14/28 同口径对比<br/>有效咨询线索台账 & 策略迭代"]
    S6 -->|"沉淀行业有效策略"| S3
```

### 四层可验收价值漏斗（拒绝单一玄学指标）

为了彻底解决客户“不知道钱花在哪、看不懂效果”的信任危机，平台将交付成果拆解为四个独立可核验层级：

1. **L1 交付执行层（100% 可控）**：官网技术阻塞修复、经审批的品牌事实库、高信息密度选型页/问答稿在目标渠道真实公开上线（凭公开 URL、内容 Hash 与版本快照签收）。
2. **L2 引擎采纳层（前置信号）**：目标页面进入搜索引擎召回池，且在目标 AI 产品的原生参考资料（Citations）或思考链（CoT）中被正向引述，品牌核心参数事实错误率下降。
3. **L3 购买推荐层（核心 GEO 指标）**：在预先冻结的 **30 道非品牌高意图购买问题**中，目标品牌被明确列为“适合选项”的推荐率（Recommendation Rate）及竞品提及份额（SoV）稳步提升。
4. **L4 业务转化层（商业终局）**：通过官网专属落地页承接、可识别 AI Referrer 会话、渠道合规组件及销售询问“您从哪里了解到我们（自报 AI 推荐）”汇总的**有效商业咨询线索（Qualified AI-Associated Leads）**。
