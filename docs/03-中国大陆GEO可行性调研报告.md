## 一、 市场与生态可行性：中国大陆 AI 搜索信源机制深度拆解

### 1.1 市场需求真实性验证
根据 CNNIC 发布的《生成式人工智能应用发展报告（2026）》，中国大陆生成式 AI 用户规模已突破 **7 亿人**，其中 **76.0%** 的用户表示会使用生成式 AI 回答问题（[CNNIC 报告介绍](https://www.cnnic.cn/n4/2026/1008/c88-11704.html)）。提问已成为这类应用的重要使用场景，传统搜索引擎（百度 PC/移动网页）流量持续向 AI 对话入口分流，B2B 采购决策者与高客单消费者越来越习惯直接提问：*“多门店连锁收银系统哪家稳定支持私有化？”*。

但目前中国大陆市场上的所谓“GEO 服务商”呈现严重两极分化：
- **低端黑灰产派**：用廉价大模型日产上千篇垃圾软文，在搜狐号、百家号、自建垃圾站群铺量灌水，甚至承诺“包上豆包/DeepSeek 第一名”。随着 2025-2026 年各大推理模型（DeepSeek-R1、豆包深度思考、元宝混元 T1）上线严苛的**信源权威度过滤与反软文推理机制**，垃圾铺量不仅迅速失效，还导致品牌被模型打上低质营销标签。
- **纯监测看板派**：照搬海外工具（如早期 Elmo 类套壳），只给客户看几个 API 跑出来的提及率折线图，既不管官网改动，也不懂国内公众号/知乎生态，客户看完报表不知道下一步该干什么，续费率极低。

**结论**：打造一套**“合规白帽 + 事实库防幻觉 + 贴合中国大陆围墙花园信源生态 + 监测到内容落地一体化”**的平台，具备极强的差异化市场空间与代理商（Agency）商业化刚需。

## 二、 技术可行性调研：监测、官网改造与多渠道分发边界

### 2.1 监测采集技术：为什么“L1 官方 API + L2 浏览器合规助手”是最优解？

我们对市面上三种采集技术路线进行了工程与法务综合评估：

| 采集路线 | 代表做法 | 稳定性与成本 | 数据真实性 | 合规与风控风险 | 最终决策 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **路线 A：纯服务端黑盒爬虫 / 逆向 App 接口** | 购买代理 IP 池、打码平台、批量小号 Cookie 池逆向抓取豆包/元宝/小红书 | **极差**（各厂每周升级滑块/设备指纹，维护人力成无底洞） | 高（直接抓 C 端） | **极高红线风险**（违反平台服务条款，涉及不正当竞争与突破计算机信息系统安全保护风险） | **坚决否决** |
| **路线 B：纯官方大模型联网 API** | 调用火山方舟 Web Search、阿里百炼 Web Search | **极高**（SLA 稳定，单次成本约 ¥0.03~¥0.18，支持定时并发） | **中等**（同厂模型+官方搜索，但检索策略与 C 端 App 存在差异，且无法覆盖元宝公众号独家索引） | **100% 合规**（官方商用企业协议） | **采纳为 L1 日常高频趋势与异常监控底座** |
| **路线 C：桌面浏览器合规辅助采集插件（Human-in-the-Loop）** | 运营人员在本地真实 Chrome 登录账号，插件辅助填词并在页面渲染后提取 DOM 文本、CoT 与引用链接 | **高**（单人 15 分钟即可完成 1 个品牌 20 道核心题在 3 个平台的 C 端采样，无服务端封禁成本） | **100% 真实 C 端**（客户在网页端看到的原生界面、思考链与参考卡片完全一致） | **合规可控**（真实人类操作会话，不绕过验证码、不破解加密协议，仅替代人工复制粘贴截图） | **采纳为 L2 真实消费者端正式基线与复测必选核验手段** |

### 2.2 客户官网 SEO 与 AI 可抓取性改造可行性
- **中国大陆常见企业官网痛点**：
  1. 大量中小企业官网使用老旧 Vue/React 纯客户端渲染（CSR）模板或慢速海外服务器，AI 实时联网搜索爬虫（抓取超时通常设在 **1.5~3 秒**，且多数实时检索器不执行重型无头浏览器渲染）拿到的是 `<div id="app"></div>` 空白壳！
  2. 产品参数全做成整张长海报图片（JPG/PNG），没有 HTML 文本表格，导致 RAG 文本抽取器完全读不到关键规格！
- **落地可行性**：无需强制客户重做整站。平台通过 HTTP + Playwright 双快照对比，10 秒内即可诊断出“JS 空壳”与“图片吞字”问题，并支持两种低摩擦交付：
  - 若客户有技术/CMS（如 WordPress / Next.js / 静态站）：提供草稿 API 或代码 PR / 独立 `/solutions/` 高性能静态 HTML 知识子目录改造方案；
  - 若客户官网短期无法大改：提供 HTML 正文改造包交由客户建站商替换，同时依靠 **微信公众号 + 知乎 + 百家号** 高权重外部信源先行承接 AI 检索。

### 2.3 中国大陆 14 大自媒体平台发布能力真实边界核验
经对各开放平台官方文档核验（拒绝听信第三方群发软件虚假宣传）：
- **第一梯队（MVP 首版支持，高 GEO 价值）**：
  - **微信公众号**：具备官方草稿箱接口（`/cgi-bin/draft/add`）与发布能力，认证账号生态成熟；首版提供**专属微信内联样式渲染包 + 可选官方草稿箱直推（D 级）**，人工在公众平台确认最终群发/发布，安全且极大节省排版时间。
  - **知乎 / 百家号 / 今日头条**：通用第三方图文自动直发 API 对普通 SaaS 均未普遍开放（头条开放平台仅开放视频权限，知乎/百家号通用写接口无公开自助开通）。首版采用 **M 级高效率半自动工作流**（生成一键带格式复制包、表格转图、声明核对单 + 回填 URL 自动巡检验证），真实可行、零封号风险。
- **第二梯队（P1/P2 按需扩展）**：
  - **抖音 / 快手 / 哔哩哔哩**：官方开放平台确有明确的 `video.create` / 视频分片上传接口（D 级文档已确认），但要求企业应用资质审核及**每次代发均须用户显式授权确认**。当试点客户具备短视频成片生产能力时，可在 P1/P2 接入官方视频发布连接器。
  - **小红书**：开放平台账号 Scope 目前仅开放 `basic_info`，笔记读写仍标为“规划中”。必须走创作服务平台人工发布，且需严格遵守去硬广导流规则。
  - **搜狐号 / 网易号 / 企鹅号 / 大鱼号 / CSDN / 掘金**：统一归入 P2 扩展池，在首版验证核心渠道 ROI 前不消耗研发工时开发专属适配器。

## 三、 法律与监管合规可行性（中国大陆上线红线）

1. **《人工智能生成合成内容标识办法》（网信办等四部门发布，2025-09-01 正式施行）**：
   - 平台 Studio 模块生成草稿时，数据库持久化记录生成模型、时间与人工修改比例（隐式元数据留痕）；导出素材包及协助发布时，自动生成显式提示声明模板并提醒运营勾选各内容平台的“含 AI 辅助生成内容”官方声明开关，严禁提供批量去除 AIGC 水印功能。
2. **数据出境与服务器部署合规（《数据安全法》《个人信息保护法》）**：
   - 数据库（PostgreSQL）、私有对象存储（阿里云 OSS）及默认大模型推理接口（火山方舟、阿里百炼、DeepSeek 国内节点）**100% 部署并运行于中国大陆境内节点（如阿里云华东/华北可用区）**。
   - 官网日志导入前强制执行脱敏规则（剔除访客完整末位 IP、手机号、Cookie/Token），不收集自然人敏感隐私。
3. **《广告法》与行业准入边界**：
   - 内置极限词与虚假宣传预检；**首期明确不承接医疗诊疗、处方药、非法金融理财、博彩等高监管风险行业客户**，聚焦合规企服 B2B 与正规消费品牌。

## 四、 商业与单品牌财务可行性测算（Unit Economics）

### 4.1 单品牌月度可变成本结构拆解（以标准套餐为例）
假设 1 个标准品牌客户配置：
- **L1 自动监测**：40 道核心题 × 2 个官方联网 API 通道 × 每天 2 次采样 × 30 天 = **4,800 次/月**（另加探索题与重试缓冲约 600 次，合计约 **5,400 次 API 联网调用/月**）；
- **L2 浏览器辅助 C 端核验**：每周 2 次 × 20 道高意图题 × 3 个真实入口（DeepSeek/元宝/豆包）= **约 480 条真实 C 端样本/月**（运营通过浏览器插件约耗时 1.5 小时/周，即 **6 小时/月**）；
- **AI 语义分析与内容生产**：每月 5,880 条回答的实体/CoT 轻量模型结构化提取 + 6~8 篇深度内容辅助生成与事实核验；
- **内容编辑与交付服务（若含代运营）**：内容运营 + 分析师复盘合计约 **12~16 小时/月/品牌**。

| 成本科目 | 保守/低单价情景 | 基准情景（推荐预算基线） | 高消耗情景（高频深度推理） | 测算依据说明 |
| :--- | ---: | ---: | ---: | :--- |
