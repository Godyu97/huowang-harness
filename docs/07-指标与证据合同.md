# 指标与证据合同

> metrics-v3｜2026-11-17｜适用所有 M0–M2；公式与以下计算样例是验收依据。所有样例为合成测试，不是产品效果。

## 1. 先限定观察集合

每张图、卡片和导出先保存 scope：品牌/实体版本、题集及题型、通道版本、来源模式、联网要求、目标/实际地区条件、语言、会话协议、统计时区、窗口、分析规则版本、is_demo=false。

不同 API、消费者入口、产品模式、联网要求和地区条件分别计算。跨轨只并排展示证据，不计算“全平台平均推荐率”。主面板仅 discovery/scenario/constraint 中不包含品牌诱导的非品牌固定题。comparison、brand_fact、exploration 各自报表，不拿品牌题提及抬高自然发现成绩。

测量单元是冻结计划槽位，不是一次请求尝试。每槽位的多个尝试只采用一个结果；重试历史保留，不能多计 P 或重复统计回答。

## 2. 集合及分母

| 符号 | 定义 | 常见边界 |
| --- | --- | --- |
| P | 冻结计划在所选已到期窗口内应完成的槽位数 | 失败/被取消的已排定槽位不删；未来计划修订只能影响尚未发生范围 |
| V | P 内有完整可分析回答、必要来源及条件信息的有效槽位 | 超时/空答/不可用截断不计；原文完整而语义未知可以计 |
| E | V 中满足冻结采样协议的合格槽位 | required 联网需触发证据为 true；未知不合格；新会话等条件也需满足 |
| Jm | E 中提及判定为 true 或 false 的槽位 | 同名歧义为 unknown，不算 false |
| Jr | E 中推荐判定为 true 或 false 的槽位 | 否定推荐为 false；含义不明为 unknown |
| C | E 中原生引用字段完整可观察的槽位 | 完整空列表属于 C；partial/unsupported 不属于 C |
| Jc | C 中官网引用判定为 true 或 false 的槽位 | 官网归属或引用归属无法确定为 unknown；无登记官网整项不适用 |
| Jo | C 中自有页面（官网+确认账号/页面）引用可判断的槽位 | 共享域名不能自动算自有 |
| Js | E 中第三方支持性可判断的槽位 | 只有完整引用集合且有关页面内容/支持关系可核验才可判断；受限造成 unknown |

Jc/Jo 补足旧口径中“链接可见但归属未知”的边界；不能把未知当未引用。所有集合均可用 observation_id 列表回溯，E≤V≤P；Jm/Jr/C≤E，Jc/Jo≤C。完整空引用在 Jc/Jo（品牌具相应登记时）中为 false，Js 中为无第三方支持。

分母为 0 显示 N/A 及原因。小样本显示提示；计数是整数，百分比展示 1 位小数，计算保留原精度。分析未就绪的样本仍可计入 V/E，但标签为 unknown，不直接补零。

## 3. 单题指标

| 指标 | 分子 / 分母 | 必须同时展示 |
| --- | --- | --- |
| 有效覆盖率 | V/P | 有效、失败、待执行/核对数 |
| 条件合格覆盖率 | E/P | 未合格原因与联网未知数 |
| 提及率 | count(Jm 且 mentioned=true)/Jm | Jm/E 与未知比例 (E−Jm)/E |
| 推荐率 | count(Jr 且 recommended=true)/Jr | Jr/E 与未知比例 (E−Jr)/E |
| 官网引用率 | count(Jc 且 official_site_cited=true)/Jc | C/E 与 Jc/C；无官网为不适用 |
| 自有页面引用率 | count(Jo 且 owned_page_cited=true)/Jo | C/E 与 Jo/C；与官网指标分开 |
| 第三方支持率（M1） | count(Js 中存在确认正向第三方支持)/Js | Js/E、不可判断原因；仅引用 URL 不等于支持 |
| 事实错误率（M1） | 人工确认含至少一条错误的回答数/已人工复核品牌事实回答数 | 复核覆盖、抽样方法；一答多错仍计一答 |

例如品牌官网已确认，回答只有完整空引用，则官网引用为 false；回答有无法确认归属的短链接，且可能指向官网，则为 unknown。若已经有一条确定官网原生引用，即使其他完整可见链接归属未知，官网引用仍为 true；只要引用集合本身 partial，仍不进入 C/Jc，保留阳性证据供查看。

## 4. 题等权聚合

默认：先逐题计算比率，再对本 scope 中有该指标可判断样本的固定题取算术平均。展示“题等权、已覆盖题数/固定题数”，并提供每题分子分母表。缺数题不按 0，也不隐去其缺失。

池化明细 = 所有题分子之和/所有题分母之和，单独标“样本池化”，不能拿池化数替代主指标。例：Q1 推荐 1/2、Q2 推荐 3/3，题等权=(50%+100%)/2=75%，池化=4/5=80%。不存在一个 75% 对应的伪造整数分母；卡片显示两题及逐题明细入口。

问题簇先汇总其成员题；同一题只能属于一个主要簇，跨簇标签不重复加权。API/C 端即使题完全相同也不合并。

## 5. 前后比较

共同题是双方满足相同题/渠道/协议/实体/分析语义且具备该指标可判断样本的交集。每个指标可以有不同共同题，必须各自显示题数、排除原因和样本数；不得用推荐的共同题数冒充引用覆盖。

先对共同题分别重算前后题等权值，再计算 delta_pp=(after−before)×100。20%→30% 为 +10pp；相对增幅 +50% 不是 +10%，默认不展示相对增幅。基线为 0 时相对增幅 N/A。无变化用未四舍五入前的结果判断，数值精度差异容忍度 1e-9。

- **M0 探索比较**：至少 3 个共同非品牌题，每题两窗至少一个可判断样本；始终显示“小样本探索，不代表稳定趋势”。引用比较还需对应 Jc，不同指标分别判定。
- **M1 正式观察**：双方 E/P≥90%；各纳入题两窗 E_q/P_q≥80%；该指标共同非品牌题数≥冻结非品牌集 80%；该指标可判断覆盖两窗均≥80%（提及 Jm/E、推荐 Jr/E、官网引用 Jc/E），且纳入题各自对应可判断覆盖≥80%。引用额外展示 C/E、Jc/C。未满足任何项降为探索或不足。
- 阈值是产品默认值，在观察开始前可按新协议版本调整，结果出现后不追溯放宽。
- 规则更新可为双方另建统一分析版本，旧版本仍保留；实体定义变更若无法完整重判两窗则不可比。
- 置信区间/显著性未经专门实现和验证不展示。不把“正式观察”写成“统计显著”或“因果提升”。

## 6. M1 竞品指标

竞品集固定为目标品牌加最多 5 个竞品。份额计算使用所有集合成员提及状态都可判断的共同 E 子集，先逐题计算各品牌提及次数/所有集合成员提及次数总和，再按共同题等权汇总。同答每品牌最多一次，多个品牌可同时提及；没有任何品牌提及的题份额为 N/A，列出覆盖，不算 0。展示题等权与池化明细。

有序推荐样本仅当回答有明确次序且为推荐语义；数字标题但无排序语义不能自动算排名。上榜率=有序样本中品牌明确被推荐的条数/可判断品牌是否上榜的有序样本数；首位率同分母，分子为位置 1。条件平均位置只对已上榜的样本计算，必须同时给上榜率；缺席不是 0。这些是本题集样本内的位置，不是搜索引擎全站排名。

## 7. 发布时间、窗口和结论

effective_at 为内容版本首次核验通过时间，claimed_published_at 为用户申报时间，二者不可混用。verified_manual 可以形成生效点，但所有报告标人工证据等级；正式计划事前可要求只接纳 verified_public，不能出结果后改。

M1 多页批次以全部指定页 effective_at 的最大值为 t0。以品牌时区 t0 所在日期为 D0，基线取 D0 前 14 个完整日；观察窗取 D0 次日起连续 7/14/28 个完整日。D0 作为上线日排除。D+7/14/28 表示累计观察检查点，区间可重叠，不能当作三个独立试验相加。

例：Asia/Shanghai，2026-11-17 15:00 全部核验完成。基线为 11-03 00:00（含）至 11-17 00:00（不含）；7 日观察为 11-18 00:00 至 11-25 00:00；后者到期后才可冻结 D+7 完整结果。若基线已包含登记干预，则不满足正式条件，重新安排基线。

结论分层：执行成果（稿件/核验数）、可见性观察、站点访问、业务反馈。前后正变化标“观察改善”，负变化标“观察下降”，都不证明因果。inconclusive 包括缺数、条件变化和未到期，不能偷换为“无效果”。

## 8. 业务与成本口径

线索按明确 event_key 去重，无法关联的不猜合并；多条证据合一条咨询。主来源优先级为 verified_ai_referral > self_reported_ai > dedicated_page_association > unknown；保留所有证据标签，不双重加总。有效咨询规则、事件窗口、会话去重各自冻结。

可识别 AI 引荐转化率 = 同组可识别 AI 引荐会话中至少产生一次合格目标事件的会话数/该组会话数。一次会话多次提交只算一个有转化会话。只有自报咨询而无会话分母时只展示计数。线索/成交与 GEO 动作的关联强度须说明，不能称因果增量。

实际费用分 settled 与 reconciliation_required；未核对费用仍预留其上界，不写零。每槽位可有多次实际供应商费用，但客户额度按冻结权益规则结算一次或显示明确额外收费确认；不得把供应商重试自动隐性转嫁客户。报告呈现费用口径与人工工时，不能把用户免费等同于业务成本零。
