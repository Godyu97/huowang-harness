# 产品 Intent：把 AI 答案里的品牌问题变成可验证的经营动作

> v3.0｜2026-11-17｜适用 M0–M2；产品名 GeoPro 为工作名称。

## 1. 产品承诺

让中国大陆品牌经营者看清：目标客户向 AI 提问时，品牌是否被正确理解、被推荐、被引用；随后用可核验事实改进内容，并在相同条件下复测。交付的是证据、动作和可复盘变化，不是固定排名保证。

产品核心单位是 **购买问题簇**。每个问题簇连接目标人群、品牌事实、AI 回答、引用页面、优化任务、内容版本、发布记录和复测结果。文章篇数、拓词数、模型图标数不是产品价值的替代指标。

## 2. 第一客群与扩展客群

首发默认面向中国大陆中小 B2B 品牌的负责人或市场运营：有清晰产品/服务、有可核实材料、能修改至少一个官网页面或自有公开内容页。先用一个行业的 3–5 个品牌验证需求；数量是招募目标，不是已取得客户。

个人品牌、小商家可以采用同一自助流程；无官网可用已确认归属的公开页面承接。纯娱乐创作者、只想批量铺稿且不愿提供事实的用户不是首发重点。首期不覆盖医疗诊疗、金融投资建议等需要专门行业审核能力的场景，此为产品范围选择。

M1 服务有内容运营与审批分工的团队；M2 服务跨品牌交付的代理商。它们共用一套证据和内容资产，逐步开放复杂能力，不另做互相割裂的“普通诊断”和“Pro 诊断”。

## 3. 用户要完成的工作

| 用户时刻 | 需要的答案 | 产品应交付 |
| --- | --- | --- |
| 第一次进入 | 从哪里开始，能看哪些 AI？ | 3 步品牌引导、真实可用入口、费用和采样范围预览 |
| 看到结果 | AI 究竟怎么说，有没有误判？ | 原问题、原回答、引用、来源条件、独立标签、可纠错证据 |
| 决定行动 | 今天先改什么，为什么？ | 最多 3 个优先建议，关联缺口、操作步骤、验收与复测方法 |
| 准备内容 | 缺什么材料，写什么才有用？ | 补证清单、事实绑定 Brief、少量可审核稿件和交接包 |
| 内容上线 | 真发出了吗，线上内容对不对？ | 公开状态、实际生效时间、版本与事实一致性记录 |
| 判断结果 | 变化可信么，下一轮怎么做？ | 可比性结论、百分点变化、数据限制、下一轮决策 |

## 4. 产品策略与取舍

- **轻入口、深证据**：首次不要求 40 题、复杂 CSP 或多角色。默认 6 个非品牌问题，最少 3 个；正式运营后再升级 40+10 模板。
- **测量与生产分开**：监测不注入私有品牌资料或指定品牌优先的提示。写作可用已批准事实；内容模拟评分不能替代外部采样。
- **先有下一步，再增加规模**：M0 包含单 API 真实采样和单消费者入口人工存证、最多 5 篇的小批次内容、官网/自有页与单渠道交付。M1 才扩持续监测和多渠道。
- **大陆渠道按证据选择**：产品入口、底层模型、API 服务、发布渠道分别记录。公众号、知乎、百家号、头条等是候选渠道，引用数据和客户权限决定优先级。
- **质量通过状态表达**：未知不等于否，失败不等于未提及，草稿不等于上线，引用不等于推荐。所有结论可追溯。
- **受控智能协助**：AI 可以归纳、拟稿和建议；事实确认、内容批准、外部公开动作各自有明确权限和记录。

## 5. 北极星与成功指标

北极星：**28 天内完成至少一次“证据 → 有效内容动作 → 公开核验 → 可比较复测”的活跃品牌占比**。分母为该滚动 28 天内至少保存过一条真实有效回答的品牌；分子为这些品牌中在该窗口内完成整条链的去重品牌。必须存在发布核验与可比报告，点击“完成”不算。该指标衡量闭环使用，不以涨幅为必要条件，避免诱导挑选好结果。

配套指标：引导完成率、首次真实报告时长 P50/P95、建议转任务率、事实补齐率、审核一次通过率、内容动作到可比复测耗时、每个合格样本及每次闭环的实际成本。各指标同时记录观察窗口和去重实体。真实业务价值用确认事实错误减少、固定非品牌题推荐率变化、可观察的有效咨询辅助判断。

M0 可用性目标：5 位目标用户中至少 4 位能在不代操作的情况下完成品牌建档和监测范围确认，操作时间中位数不超过 5 分钟（不含外部回答等待）；至少 3 位能从指标找到原文并创建有证据的任务。目标尚未实测，不能写进营销页当成果。

进入 M1 的需求信号：至少 3 个试点品牌各完成一次真实闭环，且至少 2 个希望持续监测或协作；如果用户不执行建议，优先改进事实准备、建议质量和交接体验。M2 的触发是实际多客户交付、重复手工操作和清晰的付费/授权需求。

## 6. 非目标

不建设批量洗稿、品牌替换、站群灌水、达人/媒体采购交易市场；不以某个综合“GEO 分”替代独立指标；不声称观察到了模型内部决策过程；不承诺大模型收录、固定排名或业务因果增长。不继承任一原型的技术栈、账号模式、点数价格或工程排期。

M0–M2 都不默认执行无审核的公开发布、自动改官网或无限自主 Agent 循环。产品内 AI 助理与执行本 PRD 的 coding agent 是两种不同角色。
