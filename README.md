# GeoPro（智脉 GEO）—— 中国大陆 AI 友好型监测与优化一体化平台

> **当前版本**：v2.0（全量审查重构与团队协同规范版）｜ **更新日期**：2026-11-16

本项目致力于打造面向中国大陆品牌企业与代运营机构（Agency）的 **白帽、有效、可落地 GEO（生成式引擎优化）监测与内容运营一体化 SaaS 平台**，深度适配 **DeepSeek、字节豆包、腾讯元宝、Kimi、百度 AI 搜索/文心、通义千问/夸克** 等大陆主流生成式搜索生态。

  - Next.js 16 + TypeScript Worker + Chrome 采集助手全栈技术 Spec 与状态机
  - 10 周 MVP 甘特路线图、G0-G6 阶段门禁与 **交互式单品牌成本/ROI 动态测算器**
